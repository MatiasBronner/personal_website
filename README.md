# Personal website (2025 version)

The first version of my portfolio site, built in fall 2025. It has been replaced by **[matiasbronner.com](https://www.matiasbronner.com/)**, whose source is in [personal_website_2026](https://github.com/MatiasBronner/personal_website_2026).

**Stack:** Next.js 15, React 19, TypeScript, Framer Motion

## What's in it

- A single-page layout with sections for projects, experience and skills (`src/app/page.tsx`)
- An animated text banner component (`src/components/Banner.tsx`)
- Project and experience cards generated from data arrays, so content changes don't touch the layout

## Running locally

```bash
npm install
npm run dev   # http://localhost:3000
```
